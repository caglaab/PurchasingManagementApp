# Purchasing Management Desktop Application

C# ve .NET Windows Forms kullanılarak geliştirilmiş masaüstü tabanlı Satın Alma Yönetim Sistemi.

## 📌 Proje Hakkında

Bu proje, satın alma süreçlerinin masaüstü ortamında daha düzenli şekilde yönetilmesi amacıyla geliştirilmiştir.

Uygulama üzerinden satın alma kayıtları oluşturulabilir, listelenebilir, filtrelenebilir ve analiz edilebilir. Veriler SQLite veritabanında saklanmaktadır.

## 🚀 Özellikler

- Satın alma kaydı ekleme
- Satın alma kayıtlarını listeleme
- Satın alma kaydı silme
- Satın alma kayıtlarını filtreleme
- SQLite veritabanı kullanımı
- Tedarikçi bazlı analiz
- Toplam satın alma tutarı hesaplama
- Toplam tedarikçi ve kalem sayısı
- Ortalama birim fiyat analizi
- Tedarikçiye göre grafiksel analiz
- Satın alma listesini Excel'e aktarma

## 🛠 Kullanılan Teknolojiler

- C#
- .NET 10
- Windows Forms
- SQLite
- Microsoft.Data.Sqlite
- ClosedXML
- ScottPlot

## 📊 Analiz

Analiz ekranında satın alma verileri üzerinden:

- Toplam satın alma tutarı
- Toplam tedarikçi sayısı
- Toplam kalem sayısı
- Ortalama birim fiyat
- Tedarikçi bazlı satın alma analizi
- Grafiksel satın alma analizi

sunulmaktadır.

## 📁 Veritabanı

Uygulamada SQLite kullanılmaktadır.

Satın alma kayıtları aşağıdaki temel alanlarda tutulmaktadır:

- ItemCode
- Supplier
- Quantity
- UnitPrice
- PurchaseDate
- TotalPrice

## 📤 Excel Desteği

Satın alma listesinde bulunan kayıtlar `.xlsx` formatında Excel dosyasına aktarılabilmektedir.

## 🖥 Uygulama

Masaüstü uygulaması Windows Forms kullanılarak geliştirilmiştir.
